## 1. 做法

镜像：`tmp/rooted_image/p60p_system.img`（phone system，ext4）

```sh
pkill -x Emulator ; sleep 5
# 备份原文件
mkdir -p tmp/imgbak
for f in libEGL_impl.so libGLESv1_impl.so libGLESv2_impl.so libGLESv3_impl.so; do
  debugfs -R "dump /system/lib64/$f tmp/imgbak/$f" tmp/rooted_image/p60p_system.img
done
# 换成指向 libdgles.z.so 的符号链接
for f in libEGL_impl.so libGLESv1_impl.so libGLESv2_impl.so libGLESv3_impl.so; do
  debugfs -w -R "rm /system/lib64/$f"                     tmp/rooted_image/p60p_system.img
  debugfs -w -R "symlink /system/lib64/$f libdgles.z.so"  tmp/rooted_image/p60p_system.img
done
# 让基镜像改动生效（覆盖层会盖住基镜像）
rm -f tmp/deployed_p60pv2/HarmonyOS_P60P_v2/system.img.qcow2
```

`debugfs` 的 `symlink <path> <target>` 中 target 是**链接内容**，这里用相对名 `libdgles.z.so`。
结果：

```

5361  120777  13  20-Oct-2026 17:51 libGLESv1_impl.so   -> libdgles.z.so
9556  120777  13  20-Oct-2026 17:51 libGLESv2_impl.so   -> libdgles.z.so
9557  120777  13  20-Oct-2026 17:51 libGLESv3_impl.so   -> libdgles.z.so
4586  100644  1572904            libdgles.z.so          ← 本体
```

`120777` = symlink，size 13 = `len("libdgles.z.so")`。
