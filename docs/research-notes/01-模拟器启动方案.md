# 01 - HarmonyOS 模拟器启动方案

记录如何在本机（aarch64 Linux + GNOME 桌面）使用 SDK 自带的 Emulator 启动 `phone_all_arm` 官方镜像。

## 环境

| 路径 | 说明 |
|------|------|
| `sdk/` | HarmonyOS SDK（DevEco 命令行工具），模拟器在 `sdk/emulator/Emulator` |
| `phone_all_arm/` | 官方模拟器镜像：HarmonyOS 6.1.1 / API 24 / arm64，版本 6.1.0.126 |
| `tmp/` | 所有临时文件（镜像软链、实例、日志），**不放系统 /tmp** |

镜像内容：`Image`、`ramdisk.img`、`system.img`、`vendor.img`、`sys_prod.img`、`userdata.img` + 签名与配置文件。

## 关键结论

- Emulator 是 aarch64 ELF，本机 CPU 同为 aarch64，可直接运行，支持 KVM（`/dev/kvm`）。
- 镜像根（`-imageRoot`）必须按 `system-image/<系统版本>/<abi>/` 的目录结构组织，用软链接指向真实镜像即可。
- 包装器**不支持** `-vnc` 参数透传（报 `Unknown option 'vnc'`），内置 QEMU 的 VNC 无法直接启用。
- SSH 会话无 `DISPLAY`，需加 `-noWindow`；要显示窗口则带 GNOME 会话的环境变量启动。
- hdc 工具链：`sdk/sdk/default/openharmony/toolchains/hdc`，模拟器 hdc 端口固定监听 `127.0.0.1:5555`。

## 启动步骤

### 1. 准备镜像根（只需一次）

```bash
mkdir -p tmp/image_root/system-image/HarmonyOS-6.1.1
ln -sfn <WORKSPACE>/phone_all_arm tmp/image_root/system-image/HarmonyOS-6.1.1/phone_all_arm
```

### 2. 接受许可（只需一次）

```bash
sdk/emulator/Emulator -license accept
```

### 3. 创建实例（只需一次）

```bash
sdk/emulator/Emulator -create HarmonyOS_Phone -deviceType Phone \
  -osVersion "HarmonyOS 6.1.1(24)" \
  -imageRoot <WORKSPACE>/tmp/image_root \
  -instancePath <WORKSPACE>/tmp/deployed
```

实例配置生成在 `tmp/deployed/HarmonyOS_Phone/config.ini`（机型 Pura X View，4 核 / 4G RAM / 数据盘 6G）。

### 4a. 无窗口启动（SSH / 纯命令行）

```bash
nohup sdk/emulator/Emulator -start HarmonyOS_Phone \
  -instancePath <WORKSPACE>/tmp/deployed \
  -imageRoot <WORKSPACE>/tmp/image_root \
  -noWindow > tmp/emulator_start.log 2>&1 &
```

`-noWindow` 下仍使用 GPU（GBM/EGL）渲染，只是不创建可见窗口；`-instance -screenshot` 可正常截图。

### 4b. 带窗口启动（GNOME 桌面）

```bash
env DISPLAY=:0 \
    XAUTHORITY=/run/user/1000/.mutter-Xwaylandauth.<TOKEN> \
    XDG_RUNTIME_DIR=/run/user/1000 \
    WAYLAND_DISPLAY=wayland-0 \
    DBUS_SESSION_BUS_ADDRESS=unix:path=/run/user/1000/bus \
  nohup sdk/emulator/Emulator -start HarmonyOS_Phone \
  -instancePath <WORKSPACE>/tmp/deployed \
  -imageRoot <WORKSPACE>/tmp/image_root > tmp/emulator_gui.log 2>&1 &
```

> XAUTHORITY 文件名为随机串，以 `ps -eo cmd | grep Xwayland` 查到的实际路径为准。

## 验证

```bash
# hdc 应输出 127.0.0.1:5555
sdk/sdk/default/openharmony/toolchains/hdc list targets

# 进入系统 shell，查看版本
sdk/sdk/default/openharmony/toolchains/hdc -t 127.0.0.1:5555 shell \
  "param get const.ohos.apiversion; param get const.ohos.fullname"
# 期望: 24 / OpenHarmony-6.1.1.xxx

# 截图（保存到 ~/Pictures，模拟器会走桌面截图授权弹窗）
sdk/emulator/Emulator -instance HarmonyOS_Phone \
  -instancePath <WORKSPACE>/tmp/deployed \
  -screenshot -screenshotPath <WORKSPACE>/tmp/shot.png
```

冷启动到锁屏约 1 分钟。

## 常用命令

```bash
# 停止
sdk/emulator/Emulator -stop HarmonyOS_Phone -instancePath <WORKSPACE>/tmp/deployed

# 查看实例
sdk/emulator/Emulator -list -instancePath <WORKSPACE>/tmp/deployed

# 远程桌面备选（机器已装 x11vnc，模拟器窗口模式下共享桌面 :0）
x11vnc -display :0 -auth /run/user/1000/.mutter-Xwaylandauth.<TOKEN> -forever -shared -rfbport 5900
```

## 已知事项

- 冷启动日志提示 `bootmode "snapshot" invalid`：创建实例时未开热启动（hotBoot），属正常回退。
- 窗口模式启动有 glib 插件告警 `falling back on no decorations`，仅影响窗口装饰，无功能影响。
- 模拟器自身会在系统 `/tmp` 下创建控制管道 socket（如 `/tmp/12a68e92...`），这是程序行为，与我们约定的临时文件目录无关。
