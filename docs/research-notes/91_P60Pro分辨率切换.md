# 91 P60 Pro 分辨率切换

## 变更

实例 `HarmonyOS_P60P_v2` 原屏幕配置为 Pura X View：1320×2232、480 dpi、6.39 英寸。

本次保留全部镜像和 userdata，仅修改 `tmp/deployed_p60pv2/HarmonyOS_P60P_v2/config.ini`：

```ini
hw.lcd.density=444
hw.lcd.phy.height=154
hw.lcd.phy.width=70
hw.lcd.single.height=2700
hw.lcd.single.width=1220
hw.lcd.single.diagonalSize=6.67
productModel=P60 Pro
isCustomize=true
hw.lcd.single.CutoutPath=M575 42 L645 42 v 70 h -70 Z
```

修改前配置备份为 `tmp/91_config_before_p60pro_resolution.ini`。

分辨率不支持通过现有 Emulator 控制接口热切换，因此使用 `Emulator -stop HarmonyOS_P60P_v2` 停止后，通过 `tmp/run_emu_plain.sh` 冷启动。未重置 userdata，桌面布局仍为原有的 32 行，无需重新播种。

## 验证

- host 锁屏截图：`tmp/91_p60pro_host.png`，PNG 原始尺寸 1220×2700。
- host 桌面截图：`tmp/91_p60pro_desktop_host.png`，PNG 原始尺寸 1220×2700。
- guest 内核日志显示输入设备范围为 1220×2700，图形缓冲也为 `w 1220 h 2700`，不只是外层窗口缩放。
- 实际执行上滑解锁成功，桌面 APP 图标与 Dock 完整，触摸坐标在新分辨率下有效。
- `bootevent.boot.completed=true`，SELinux 保持 `Enforcing`。

`Emulator.log` 同时确认加载自定义配置并记录 `Init Phone dpi = 444`。

## 备注

root 下直接运行 `snapshot_display` 仍返回 `GetDisplayById ... error`，与此前已知的 displayId/access-token 工具链限制一致；本次未因此判定 guest 显示失败，guest 内核输入范围与实际图形缓冲均已独立核实。
