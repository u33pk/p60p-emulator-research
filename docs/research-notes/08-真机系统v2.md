# 08 - 真机系统 v2：模拟器 6.0.0 版（版本对齐方案）

将模拟器部件从 6.1.1 换成 **HarmonyOS 6.0.0(20)/6.0.0.48**（与真机 ROM 6.0.0.107 同版本线），彻底解决 6.0↔6.1 ABI 错配类问题。

## v2 架构

| 部件 | 来源 | 处理 |
|------|------|------|
| Image / ramdisk | 6.0.0 镜像 | 原生，无修改（ext4 路径自动 SwitchRoot） |
| system.img | 真机 6.0.0.107 | EROFS→ext4 重打包 + root 注入（沿用 v1 成果） |
| vendor.img | 6.0.0 镜像副本 | 删 `prebuild_sepolicy/`（强制开机编译真机 cil → permissive 生效） |
| sys_prod / userdata | 6.0.0 镜像 | 原生（含 PHEMU-FD00 variant，bind 挂载通过） |

- imageRoot：`tmp/image_root_p60pv2/system-image/HarmonyOS-6.0.0/phone_all_arm/`
- 实例：`HarmonyOS_P60P_v2`（instancePath `tmp/deployed_p60pv2`）
- 额外注入（沿用）：模拟器 hdcd（express_bridge 桥接）、4 个 GPU impl 库
- 已回滚的 hack：musl ini 场景隔离（hdf61/realhdf）——版本对齐后无必要

## 版本对齐消灭的问题（v1 的补丁全部不再需要）

| v1 问题 | v2 结果 |
|---------|---------|
| pin_auth_host exit 127（IPC 符号级联） | ✅ 原生存活（`pidof pin_auth_host` 有值） |
| devmgr 缺失（6.1 vendor 无 devmgr） | ✅ 6.0.0 vendor 自带 `/bin/hdf_devmgr` + cfg |
| devmgr SA 注册 ABI 断裂（6.1 devmgr ↔ 6.0 samgr） | ✅ 不存在（未借用，天然同版本） |
| hdf61 musl 场景隔离 | ✅ 已回滚 |
| HDF 服务管理器链路 | ✅ `failed to get sa hdf service manager` 消失 |

## v2 已知问题：桌面 UI 未就绪

**现象**：`bootevent.bootanimation.finished=true`（开机动画正常播完=显示硬件链路通），但 `bootevent.wms.fullscreen.ready` 不置位，launcher 不起，DMS 反复 `GetPrimaryDisplayInfo ... failed`。

**排查结论**（证据链）：
1. composer_host 存活且已加载 `libdisplay_composer_driver_1.0`，devmgr/驱动加载无 avc 拒绝
2. RS 能按名拿到 `display_composer_service`（有 composer_host 时无 RS 报错）
3. 移除 composer_host 后 RS 报 `get hdi service display_composer_service failed` 且**不回落 VDI**
4. **关键对比**：v1（无 devmgr）RS 报的是 `failed to get sa hdf service manager`（更底层失败）→ 触发了 VDI 回落 → UI 正常；v2 servmgr 可达但服务/数据不完整 → 不回落 → 卡住
5. 真机 sys_prod variant（ALN-AL00 等）只有 cust/param/settings，窗口/图形配置真机放在 system——emulator 的 `/sys_prod/etc/window` bind 内容真机系统未必按同路径消费

**待验证方向**：
- 真机 DMS 获取主屏信息的完整调用链（`ScreenSessionManager::GetPrimaryDisplayInfo` 的 6.0.0.107 源码）
- 是否差某个真机 display HAL 服务（hisi 风格 sysfs 依赖）
- 终极方案：让 RS 走 VDI（需 servmgr 整体不可达，与 pin_auth 冲突，二选一）

## 启动命令

```bash
# 原版 6.0.0 自检实例：HarmonyOS_600_test（tmp/deployed_600）
# v2 真机系统：
sdk/emulator/Emulator -start HarmonyOS_P60P_v2 \
  -instancePath <WORKSPACE>/tmp/deployed_p60pv2 \
  -imageRoot <WORKSPACE>/tmp/image_root_p60pv2 -noWindow
# hdc（daemon 重启后第一次需手动注册）：
sdk/sdk/default/openharmony/toolchains/hdc tconn 127.0.0.1:5555
```
