# 05 - 真机镜像（p60p）启动成功

P60 Pro 真机 ROM（OpenHarmony-6.0.0.107）在模拟器中启动成功，hdc 获得 root。

## 最终方案

**镜像组合**（imageRoot = `tmp/image_root_p60p`）：

| 分区 | 来源 | 说明 |
|------|------|------|
| Image / ramdisk | 模拟器原版 | 内核 + 一阶段 init（真机内核加密，不折腾） |
| system.img | **真机解包→ext4 重打包 + root 注入** | `tmp/rooted_image/p60p_system.img` 6G |
| vendor.img | **模拟器已 root 版** | `tmp/rooted_image/vendor.img`（express 平台 HDF 驱动） |
| sys_prod / userdata | 模拟器原版 | sys_prod 有机型 bind 挂载依赖 |

**启动验证**：`hdc shell id` → `uid=0(root)`，`param get const.ohos.fullname` → `OpenHarmony-6.0.0.107`，真机应用（AILife、AdminProvisioning 等）在位。

## 关键机制（全部经 kernel.log + 源码实证）

1. **挂载逻辑**：init 一阶段按 cmdline `ohos.required_mount.*` 挂载；设备是 EROFS 而 fstype 写 ext4 时**直接跳过**（假成功）→ 必须 ext4（或 cmdline 写 erofs）
2. **SwitchRoot("/usr")**：ext4/erofs 挂载点 `/usr` 成功后切换根到 system 分区；ramdisk 中的 `/bin→/system/bin` 等符号链接在切换后由真机镜像内同名结构接管
3. **内核支持 EROFS**（magic 自动识别），但 cmdline 由 wrapper 写死 ext4 且 **bootArgs 不进 cmdline**、**wrapper 二进制有自校验**（patch cmdline 字符串→静默退出），故放弃改 wrapper
4. **SELinux 策略**：开机由 init 编译 cil（`/system/bin/secilc`）；真机 vendor 带预编译策略（跳过 cil 编译），须删除预编译强制走 cil；`system.cil` 有防篡改校验**不加载**，注入点只能是 `system_common.cil`

## 踩坑记录（按出现顺序）

| 坑 | 现象 | 解法 |
|----|------|------|
| sys_prod 机型 bind 挂载 | init 等 5s×2 后死亡 | 换回模拟器 sys_prod（有 PHEMU-FD00 variant 目录） |
| EROFS 跳过挂载 | exec /bin/init ENOENT | EROFS→ext4 转换 |
| ext4 根 inode 无标签 | 全体服务 execve EACCES→exit 127 | debugfs 补 `ea_set / security.selinux rootfs` |
| 真机 vendor（麒麟 HAL） | hdf_devmgr EINVAL 死循环→bootfail | 换模拟器 vendor（express 驱动 + 模拟器内核） |
| 真机 hdcd 无桥接 | hdc 空 | 注入模拟器 hdcd（依赖真机全有）；桥接设备 `/dev/express_bridge` 内核自带、ueventd 自动建节点 |
| hdc 守护进程注册 | tconn 前 list 为空 | `hdc tconn 127.0.0.1:5555` 手动注册 |

## 转换管线（全免 sudo）

```bash
# 1. EROFS 解包（xattr 会丢，后面补）
fsck.erofs --extract=tmp/p60p_tree/system tmp/unpack_out/unpack_result_221524/system.img
# 2. 树内注入：ohos.para(secure=0/debuggable=1)、hdc.para(usb=enable)、
#    hdcd.cfg(root版)、system_common.cil(typepermissive sh/hdcd)、删 vendor 预编译策略
# 3. 重打包
mke2fs -q -t ext4 -b 4096 -O ^has_journal -d tmp/p60p_tree/system tmp/rooted_image/p60p_system.img 6G
# 4. 批量打标：file_contexts 正则匹配（最长前缀胜出），debugfs ea_set + sif uid/gid 0
#    注意：镜像根目录 "/" 必须单独打标签（rootfs）——漏掉=全盘 exec EACCES
# 5. 注入模拟器 hdcd（debugfs write /system/bin/hdcd）
```

## hdc 连接方式

```bash
sdk/sdk/default/openharmony/toolchains/hdc tconn 127.0.0.1:5555
hdc -t 127.0.0.1:5555 shell id    # uid=0(root)
```

（真机系统 usb 配置走 hisi UDC，ffs.hdc 在模拟器内核上同样失败——但这不影响，hdc 桥走 express_bridge）

## 已知缺口（后续可做）

- **无显示**：composer_host 等 HDF devhost（模拟器 vendor）exit 127——与真机系统库 ABI 不完全兼容；用户已确认暂不要求 GPU/显示
- chip_prod / cust / modem 等真机分区未挂载（无对应槽位）：部分 HAL/功能缺失
- sys_prod 用的模拟器版：真机 sys_prod 因机型 bind 挂载暂时无法换回
