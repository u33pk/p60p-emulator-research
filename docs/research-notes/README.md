# 历史调研笔记

这里保留 90 篇按实验时间编号的记录，内容包括成功结果、失败实验、误判和后续更正。它们用于理解问题怎样被逐层定位，而不是一套可以直接顺序执行的安装教程。

请优先阅读仓库 `docs/` 下的最终文档。历史笔记中的绝对路径已替换为 `<WORKSPACE>`、`<HOME>` 等占位符；截图和二进制仍然只引用原实验位置，并未随笔记分发。

推荐主线：

1. `02`～`07`：解包、root、SELinux 和初步启动；
2. `18`～`29`：显示、Vulkan、DGLES TLS 和缓冲问题；
3. `39`～`43`：区分 host 占位图与 guest 真实帧；
4. `52`～`55`：GL/Vulkan 分支与 boot-complete 根因；
5. `71`～`76`：稳定出屏、身份参数和恢复 Enforcing；
6. `77`～`88`：冻结、输入、显示使能、EGL/mmap 与最终交互验收；
7. `89`：桌面无图标根因与 userdata 自动修复；
8. `91`：1220×2700 分辨率验证。

较早文档若与较后文档冲突，以较后实验和最终文档为准。
